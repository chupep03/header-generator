# Описание функций расширения Code Generator

## Основные функции

### `activate(context)`
**Назначение**: Активация расширения и регистрация команд  
**Параметры**:
- `context` - контекст расширения VS Code  
**Описание**: Регистрирует команду `code-generator.analyzeAndGenerateHeader` в палитре команд VS Code.

### `generateHeaderFromCode(filePath, fileContent)`
**Назначение**: Функция собирающая воедино анализ кода с последущей генерацией хэдер файла  
**Параметры**:
- `filePath` - путь к исходному файлу
- `fileContent` - содержимое исходного файла  
**Описание**: Координирует процесс получения различных элементов кода и генерации заголовочного файла.

## Функции извлечения элементов кода

### `ExtractFunctions(code)`
**Назначение**: Извлечение функций из исходного кода  
**Параметры**:
- `code` - строка с исходным кодом  
**Возвращает**: Массив объектов с кодом объявлений функций  
**Формат возвращаемых данных**:
```javascript
{
    name: string,        // имя функции
    returnType: string,  // тип возвращаемого значения
    signature: string    // полная сигнатура функции
}
```

### `ExtractClasses(code)`
**Назначение**: Извлечение классов  
**Параметры**:
- `code` - строка с исходным кодом  
**Возвращает**: Массив с именами классов

### `ExtractStructs(code)`
**Назначение**: Извлечение структур  
**Параметры**:
- `code` - строка с исходным кодом  
**Возвращает**: Массив с именами структур

### `ExtractIncludes(code)`
**Назначение**: Извлечение #include  
**Параметры**:
- `code` - строка с исходным кодом  
**Возвращает**: Массив строк с включениями

## Функции генерации и сохранения

### `generateHeaderContent(fileName, includes, functions, classes, structs)`
**Назначение**: Генерация текста заголовочного файла  
**Параметры**:
- `fileName` - имя исходного файла
- `includes` - массив директив #include
- `functions` - массив функций
- `classes` - массив классов
- `structs` - массив структур  
**Возвращает**: Строку с готовым содержимым заголовочного файла

### `saveHeaderFile(originalFilePath, headerContent)`
**Назначение**: Сохранение сгенерированного заголовочного файла
**Параметры**:
- `originalFilePath` - путь к исходному файлу
- `headerContent` - содержимое для сохранения  
**Описание**: Предлагает пользователю варианты сохранения файла(сохраить, сохранить как, отменить сохранение)

### `deactivate()`
**Назначение**: Деактивация плагина  
**Описание**: Вызывается при отключении плагина, выполняет очистку.

## Регулярные выражения

В коде используются следующие регулярные выражения:

- **Функции**: `/(\w+)\s+(\w+)\s*\(([^)]*)\)\s*\{/g`
- **Классы**: `/class\s+([a-zA-Z_][a-zA-Z0-9_]*)\s*\{/g`
- **Структуры**: `/struct\s+([a-zA-Z_][a-zA-Z0-9_]*)\s*\{/g`
- **include**: `/#\s*include\s*<[^>]+>/g`

## Особенности работы

- Автоматически генерирует заголовки на основе имени файла
- Игнорирует функцию `main` при извлечении функций
- Предоставляет интерфейс для сохранения заголовочного файла
